DESCUBRE ESPAÑA — TRAVEL GUIDE + QUIZ

HOW TO OPEN
1. Keep all files in this folder together.
2. Open start.html in a browser, or open this folder in Visual Studio Code and use Live Server.
3. Choose GUÍA DE VIAJE to open the original travel planner.
4. Choose QUIZ DE ESPAÑA to open the quiz by Sairupesh (25BCE1578).

QUIZ FEATURES
- Welcome page, Quiz, Leaderboard, My Experience section (Spanish + English), and Cover navigation.
- Participant name, registration number, and email are required before question 1 appears.
- 60 Spanish multiple-choice questions: 20 easy, 20 medium, and 20 hard.
- Choose a difficulty before starting: Easy (20 questions, 1 point per correct answer, max 20), Medium (20 questions, 3 points each, max 60), Hard (20 questions, 5 points each, max 100), or Mixed (all 60 questions shuffled, 20 from each difficulty, 1 point each, max 60).
- The leaderboard can be filtered by mode. Each mode has a separate ranking because the point values and maximum scores differ; scores sort by points, then accuracy, then completion time.
- The leaderboard stores results in the current browser's localStorage. It is not a shared online leaderboard and does not send data to a server.
- Use the Cover / Portada button to return to start.html.
